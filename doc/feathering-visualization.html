喷墨羽化，是点的分配

在重叠区域，将已有的二值点分派给不同 PASS；不是把每个像素乘以渐变系数，更不是连续颜色混合。

两 PASS 教学模型 离线 · 确定性采样
先区分两个坐标系。 上层几何决定两次扫描在介质上的重叠带；PASS 局部喷嘴行坐标则以各自扫描窗口为原点，不能直接当作同一个全局行。本例将共同画布的 y 轴（画面行）设为沿纸进 / 重叠方向向下；这是教学约定，不代表所有设备的实际纸进方向。A 窗口为 [0, 重叠末行]，B 窗口为 [重叠首行, 末行]；在各自窗口内，A 局部喷嘴行 = 全局 y，B 局部喷嘴行 = 全局 y − 重叠首行。真实设备的窗口、步进和行映射由上层决定。

概率是选点规则，不是像素亮度

M_A = [阈值(x,y,seed) < p_A(y)]　 M_B = 1 − M_A
outA = I & M_A　　outB = I & M_B
(outA | outB) = I　　(outA & outB) = 0

以上互补关系仅针对本例的重叠区与硬切/羽化；非重叠区由覆盖窗口指定唯一 PASS。不处理模式在重叠区令两个 mask 都为 1，不满足互补。p 是重叠带内每个位置分给 A 的目标概率；线性从 1 到 0，正弦为平滑端点，B 概率为 1−p。共享确定性阈值场按像素采样，不是 DLL 的 rytemp 算法。

对应 DLL 实现及边界

以下是 ImgSource-masks-analysis.md 对汇编的静态解读，并非已运行验证的源码；字段物理单位与上层调用关系并未全部确认。

  • InitFeatherData 0x180004450：依据参数与模式分配过渡 / 核心行并初始化羽化形状；实际行映射不等同于本例假设。
  • InitShapeFearther 0x180003D60：构造灰度坡度（常规模式正弦；mode 7 线性）→ 外部 rytemp.dll 二值化 → CRT rand 横向采样扰动、取反与部分模式修正 → 每 PASS 不同窗口输出。rytemp 的二值化与可能的随机性未知。
  • FeatherProc 0x180004CB0：根据局部行与 PASS 选取 mask，将现有数据按位 AND；并不证明最终所有 PASS 严格互补。

边界：本 demo 仅展示两 PASS 共享阈值的互补教学模型，不是 DLL 严格多 PASS 复现，也不声称复刻未知的 rytemp、真实种子、喷嘴映射或物理打印结果。局部取反不等于完整打印任务的墨滴或颜色守恒。
